# Bubble
A lightweight graphical interface for roleplaying with LLMs.

## Design principles
Prioritize clean code.
Use snake_case for variables and most things. For other things, follow conventions.

Recommended patterns:
- Early return/break/continue

Discouraged patterns:
- Class

Respect pre-established coding styles shown in the files, including:
- Being laconic and explicit at the same time, if possible
- Writing context-dependant clean CSS class names instead of long descriptive redundant ones 
- Using lh (lineheight) and ch (horizontal character size) as the default units for sizing most css properties
- Reusing pre-established CSS variables instead of arbitrary values
- Just do not style if you are unsure.

When you are making a change, explicitly state your plan before you initiate, and explicitly summarize what/how/why you did after finishing the work.
Do not silently make unasked changes, but you can suggest some changes.

Do not forget; write less than more; prune rather than to add.
