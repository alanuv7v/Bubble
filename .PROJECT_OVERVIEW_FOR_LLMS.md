# Bubble

Bubble is a lightweight, personal interface for configurable AI conversations. Its direction is local-first, user-controlled, and usable on desktop and in the browser. Cross-platform support is a goal; verify what is currently implemented.

## Design principles

- Keep user data under the user's control. Sending a prompt to an external model shares it with that provider.
- Keep chats, characters ("Bubbies"), prompts, and model settings distinct and reusable.
- Let users configure models and providers; do not hard-code one into the product's core.
- Prefer clean, direct, lightweight code over unnecessary frameworks or abstractions. Follow local naming conventions; snake_case is preferred.
- Keep platform-specific behavior at clear boundaries. Do not assume a runtime is supported because detection or scaffolding exists.

These are inferred intentions, not a feature specification. Current code determines current behavior; newer explicit decisions take precedence.

Do not forget; write less than more; prune rather than to add.
